2.1 Introduction

This document runs one project year’s raw lab files through ingestion, QA/QC evaluation, WQX formatting and CDX export. Everything year-specific is read from config.yml, year_files/ and reference/.

The structure of Part C follows the Data Evaluation Checklist provided by the Alaska Department of Environmental Conservation. Results that fail QA/QC are marked Rejected before upload to the EPA Water Quality Exchange (WQX); they remain in the public record.

Question tags in Part C (AUTO, MANUAL, MIXED) are provisional and show how much of each answer the pipeline can compute. Chunks marked eval: false are not yet ported from project_year/2025.qmd.

Hold time is the elapsed time from collection to the start of analysis, compared with reference/wqx_templates/sample_holding_times.csv. In-situ meter readings are Not applicable. # Annual QA/QC Pipeline {.unnumbered}

## Introduction

This document runs one project year's raw lab files through ingestion, QA/QC evaluation, WQX formatting and CDX export. Everything year-specific is read from `config.yml`, `year_files/` and `reference/`.

The structure of Part C follows the Data Evaluation Checklist provided by the Alaska Department of Environmental Conservation. Results that fail QA/QC are marked Rejected before upload to the EPA Water Quality Exchange (WQX); they remain in the public record.

Question tags in Part C (AUTO, MANUAL, MIXED) are provisional and show how much of each answer the pipeline can compute. Chunks marked `eval: false` are not yet ported from `project_year/2025.qmd`.

------------------------------------------------------------------------

## Setup

```{r setup, message=FALSE, warning=FALSE}
library(tidyverse)
library(readxl)
library(janitor)
library(lubridate)
library(here)

config <- yaml::read_yaml(here("config.yml"))
year <- config$year

# format_wqx.R expects the spring date as M/D/YYYY
spring_d <- ymd(config$sampling$spring_date)
spring_sample_date <- sprintf("%d/%d/%d", month(spring_d), day(spring_d), year(spring_d))

cfg <- list(
  year                  = year,
  templates_dir         = here("reference/wqx_templates"),
  wqx_template_file     = here("year_files", paste0("AWQMS_KWF_Baseline_", year, ".xlsx")),
  wqx_intermediate_path = here("output/intermediate", paste0(year, "_kwf_baseline_results_wqx.csv")),
  flagged_export_path   = here("output/intermediate", paste0(year, "_export_data_flagged.csv")),
  flag_decisions_path   = here("year_files", paste0(year, "_data_flag_decisions.csv")),
  # Moves into the template layout when the repo is blanked (Phase E)
  wqx_downloads_dir     = here("other/input/WQX_downloads"),
  spring_sample_date    = spring_sample_date,
  summer_sample_date    = config$sampling$summer_date
)

dir.create(here("output/intermediate"), recursive = TRUE, showWarnings = FALSE)
```

------------------------------------------------------------------------

## Pipeline Run

Required order: combine_dat, assess_lab_qc, assign_qc_status, assess_holding_times, format_wqx, apply_qaqc_flags, generate_cdx_export. The `format_wqx.R`, `apply_qaqc_flags.R` and `generate_cdx_export.R` scripts read and write the global environment.

```{r pipeline, message=FALSE, warning=FALSE}
fn_files <- c("resolve_rm_site", "numeric_utils", "clock_utils", "check_dat_contract",
              "ingest_sgs", "ingest_fc", "ingest_tss", "ingest_ysi", "combine_dat",
              "assess_lab_qc", "assign_qc_status", "assess_holding_times")
for (f in fn_files) source(here("functions", paste0(f, ".R")))

res <- combine_dat(config)
lab_qc <- assess_lab_qc(res$lab_qc)
qc <- assign_qc_status(res$dat, res$sample_batches, lab_qc, config$qc$blank_multiple)
dat <- qc$dat
# Row key shared with format_wqx.R, which keeps an existing dat_row
dat$dat_row <- seq_len(nrow(dat))
lab_qc_actions <- qc$lab_qc_actions

# Q17 hold times feed the QC status, so they are assessed before the export is finalized
holding_times <- assess_holding_times(
  dat,
  read.csv(file.path(cfg$templates_dir, "sample_holding_times.csv")),
  read.csv(file.path(cfg$templates_dir, "in_situ_methods.csv"), colClasses = "character")
)

source(here("functions/format_wqx.R"))
source(here("functions/apply_qaqc_flags.R"))

# The CDX export needs station and project downloads from WQP; skip when absent
wqp_project_file <- file.path(cfg$wqx_downloads_dir, "project/project.csv")
if (file.exists(wqp_project_file)) {
  source(here("functions/generate_cdx_export.R"))
} else {
  message("generate_cdx_export skipped: WQP downloads not found in ", cfg$wqx_downloads_dir)
}

# Inputs for prelim_report.qmd
write.csv(export_dat, here("output/assessed_results.csv"), row.names = FALSE)
write.csv(lab_qc, here("output/lab_qc_assessed.csv"), row.names = FALSE)
```

**17.) Were preservation, hold time and temperature requirements met?**

Hold time is the elapsed time from collection to the start of analysis, compared with `reference/wqx_templates/sample_holding_times.csv`. In-situ meter readings are Not applicable. A missing time of day is bracketed (earliest and latest possible elapsed time); a row is Not evaluable only when the answer depends on the missing value, or when the method has no limit in the table.
```{r q17-holdtimes}
holding_times |>
  filter(hold_status != "Not applicable") |>
  summarise(
    results = n(),
    limit_hours = first(max_hold_hours),
    max_elapsed_hours = if (all(is.na(elapsed_hours))) NA_real_ else max(elapsed_hours, na.rm = TRUE),
    pass = sum(hold_status == "Pass"),
    fail = sum(hold_status == "Fail"),
    not_evaluable = sum(hold_status == "Not evaluable"),
    .by = c(lab_name, epa_analysis_id)
  )
```

```{r q17-exceptions}
holding_times |>
  filter(hold_status %in% c("Fail", "Not evaluable") | receipt_check == "Out of order") |>
  select(sample, analyte, lab_name, epa_analysis_id, elapsed_hours, max_hold_hours,
         hold_status, hold_note, receipt_check)
```

The table above is empty when every evaluable result passed and every recorded receipt is in order.

```{r q17-receipt}
holding_times |>
  filter(receipt_check != "Not applicable") |>
```
